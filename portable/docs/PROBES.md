commands that security tooling may flag; `net` (`--net`) adds reachability checks against
proxies and mirrors found in local configuration.

## What each probe reads or runs

- `os.identity`: OS family, version, build, edition, kernel, architecture, domain or directory join.
- `os.time_locale`: Time zone, locale, decimal separator and code pages change parsing, sorting and file encodings.
- `os.health`: Last boot, load and whether a reboot is pending (installers and updates may be blocked).
- `os.updates`: Hotfix inventory; legacy systems need specific updates for UCRT, SHA-2 and TLS 1.2.
- `hw.cpu`: Model, cores and instruction sets (AVX, AVX2, AVX-512, NEON) required by prebuilt binaries.
- `hw.memory`: Physical memory, available memory, swap or page file.
- `hw.storage`: Mounted volumes, file system types, free space, network and removable volumes.
- `hw.gpu`: Display adapters and drivers (CUDA, OpenGL and headless rendering).
- `limits.process`: Open files, processes, stack, locked memory and core dump limits (soft and hard).
- `limits.kernel`: inotify, max_map_count, somaxconn, pid and thread limits, ptrace and namespace settings.
- `limits.cgroup`: Container or slice CPU, memory and pids limits that are smaller than the host.
- `net.ports`: Ephemeral ranges, excluded or reserved port ranges, unprivileged port start, HTTP URL ACLs.
- `user.identity`: User, groups, elevation, home directory and whether the account exists in passwd.
- `user.profile`: Roaming, temporary or mandatory profile, folder redirection, OneDrive, home on a network share.
- `user.privileges`: Full token and privilege list, applied user GPOs, sudo rules (may raise security alerts).
- `env.vars`: Process, user and machine environment (secret values redacted).
- `env.path`: PATH entries: missing, duplicate, relative, network and user-writable directories.
- `shell.info`: Shell implementations and versions, PowerShell language mode and execution policy, umask.
- `shell.userland`: GNU, BSD or busybox variants of sed, awk, grep, tar, date and find (script portability).
- `sec.app_control`: AppLocker, SRP, WDAC, Smart App Control, SELinux, AppArmor, fapolicyd, seccomp, SIP, Gatekeeper.
- `sec.crypto`: FIPS mode, TLS protocol policy, .NET strong crypto, system crypto policy.
- `sec.av`: Registered antivirus products, Defender attack-surface policy, full policy hive.
- `tls.trust`: Enterprise and TLS-inspection roots, root auto-update, bundles and per-runtime CA settings.
- `pkg.sources`: Registry and mirror configuration for npm, pip, Maven, Gradle, NuGet, cargo, Go, OS repos and git.
- `pkg.caches`: Local dependency caches that make offline builds possible.
- `pkg.installed`: OS package inventory and installed applications.
- `pkg.features`: Enabled Windows optional features (IIS, .NET 3.5, WSL, Hyper-V, containers).
- `tools.inventory`: Which runtimes, compilers and tools exist, their versions, paths and binary architecture.
- `runtime.version_managers`: rustup, volta, asdf, mise, pyenv, nvm and similar: installed versions, read without running shims.
- `runtime.java`: JDKs and JREs found via JAVA_HOME, PATH and known locations (from their release files).
- `tls.java_cacerts`: Whether the JDK truststore contains the enterprise roots (runs keytool).
- `runtime.dotnet`: .NET Framework release, .NET SDKs and runtimes.
- `runtime.python`: Python interpreters if any, including Windows Store aliases and the py launcher.
- `toolchain.msvc`: Visual Studio instances (vswhere), Windows SDKs and MSBuild.
- `native.deps`: C runtime (glibc, musl, UCRT), libstdc++, OpenSSL, VC++ redistributables, WebView2, ODBC drivers.
- `net.interfaces`: Interfaces, addresses, MTU, gateways and DNS servers.
- `net.routes`: Default gateways and routing table.
- `net.dns`: DNS servers, search suffixes, hosts file entries and resolver order.
- `net.proxy`: Proxy environment, WinHTTP (services) versus WinINET/PAC (user), system and package-manager proxies.
- `net.listening`: TCP ports already in use on this host.
- `net.netstat`: Full socket table via netstat where no quiet source exists.
- `net.firewall`: Host firewall state where readable without admin rights.
- `net.reachability`: DNS and TCP checks against proxies and mirrors found in local configuration only.
- `fs.mounts`: File systems and options (noexec, nosuid, ro) for temp, shared memory, home and root.
- `fs.locations`: Which candidate install, temp and data directories this user can write, and their free space.
- `fs.semantics`: Case sensitivity, symlink and hard link creation, long paths, short names, name length limits.
- `fs.exec_test`: Writes and runs a trivial script in each writable location (may log application-control events).
- `proc.list`: Process inventory (only this user's command lines are visible).
- `svc.list`: Services or units, their state, start mode and service accounts.
- `sched.tasks`: Scheduled tasks, cron entries, systemd timers and user lingering.
- `virt.platform`: Hypervisor, VM vendor, container or Kubernetes, WSL, container engine sockets.
- `virt.engine`: docker info or podman info against a local socket only.
- `session.context`: Console, RDP, SSH or service session, interactive or headless, terminal and display.
